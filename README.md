# Portafolio de Proyectos - Ramiro Silva (RakkoTV)

¡Bienvenido a mi portafolio! Aquí encontrarás una colección de mis proyectos, herramientas, experimentos y plugins para OBS Studio.

---

## 🚀 Proyectos Destacados (OBS Tools Suite)
He desarrollado una suite completa de herramientas para OBS Studio, diseñadas para automatizar tareas, mejorar la calidad de streaming y optimizar el flujo de trabajo.

### Plugins (C++)
- [AI-Powered Dynamic Noise Gate](plugins/AI-NoiseGate/README.md) - Filtro inteligente de ruido.
- [PTZ Auto-Tracking Dock](plugins/PTZ-Tracking/README.md) - Seguimiento automático para cámaras PTZ.
- [Serial Data Bridge Overlay](plugins/Serial-Bridge/README.md) - Integración de datos de hardware.
- [Advanced Text Ticker Pro](plugins/Text-Ticker/README.md) - Scroll de texto avanzado.
- [Twitch Ingest Optimizer](plugins/Ingest-Optimizer/README.md) - Optimización de servidores.

### Scripts (Lua)
- [Auto-Naming & Metadata](scripts/Auto-Naming/README.md) - Organización automática de archivos.
- [Cam-Sync](scripts/Cam-Sync/README.md) - Sincronización de grabación externa.
- [Weather-Alert Automation](scripts/Weather-Alert/README.md) - Alertas climáticas en vivo.
- [Live Delay Adjuster](scripts/Delay-Adjuster/README.md) - Ajuste dinámico de retraso.
- [Smart Replay Organizer](scripts/Replay-Organizer/README.md) - Gestión de clips del buffer.

---

## 🛠️ Stack Tecnológico
- **Frontend:** React, Next.js 15, Vue 3, Tailwind CSS, TypeScript.
- **Backend:** PHP, Node.js, Python.
- **Streaming:** OBS Studio (Plugins/Scripts en LUA/C++).
