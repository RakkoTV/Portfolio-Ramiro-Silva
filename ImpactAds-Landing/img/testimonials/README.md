# Imágenes para la sección de Testimonios

Esta carpeta contiene imágenes de alta definición para la sección de testimonios del sitio web.

Recomendaciones:
- Resolución recomendada: 200x200px para avatares
- Formato: JPG o WebP para mejor rendimiento
- Usar imágenes profesionales de los testimonios
- Considerar usar imágenes con fondo transparente (PNG) para mejor integración
