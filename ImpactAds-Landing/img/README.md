# Carpeta de imágenes

Esta carpeta contiene todas las imágenes de alta definición utilizadas en el sitio web.

Las imágenes están organizadas en las siguientes categorías:
- hero: Imágenes para la sección principal
- features: Imágenes para la sección de características
- showcase: Imágenes para la sección de muestra
- testimonials: Imágenes para la sección de testimonios
- logos: Logotipos e iconos
