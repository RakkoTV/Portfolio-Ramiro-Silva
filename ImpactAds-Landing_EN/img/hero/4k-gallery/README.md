# Imágenes 4K para la Galería Hero

Esta carpeta contiene imágenes de ultra alta definición (4K) para la galería de la sección hero del sitio web.

Recomendaciones:
- Resolución: 3840x2160px (4K UHD)
- Formato: JPG o WebP optimizados para web
- Tamaño máximo recomendado: 1-2MB por imagen para mantener buen rendimiento
- Usar imágenes con buena relación de aspecto para la visualización en la galería
- Mantener coherencia visual con el estilo del sitio
