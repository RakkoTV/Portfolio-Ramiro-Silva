# Imágenes para la sección Showcase

Esta carpeta contiene imágenes de alta definición para la sección de muestra (showcase) del sitio web.

Recomendaciones:
- Resolución recomendada: 1200x800px o superior
- Formato: JPG o WebP para mejor rendimiento
- Usar imágenes que ilustren claramente el producto o servicio
- Mantener un estilo visual coherente con el resto del sitio
